# Утренняя сводка — облачная версия

Каждое утро сервер GitHub сам собирает сводку и выкладывает её на сайт.
Компьютер включать не нужно. Читать можно с телефона, iPad, Mac и Windows: просто открой ссылку.

## Что в этой папке

| Файл | Что это |
|---|---|
| `morning_news.py` | скрипт: собирает новости, отдаёт их Claude, делает страницу |
| `config.json` | источники и настройки |
| `template.html` | дизайн страницы |
| `.github/workflows/news.yml` | расписание: каждый день около 7:30–8:00 по Москве |
| `.gitignore` | служебный файл для GitHub |

Загружать на GitHub нужно **всё содержимое этой папки**.

## Настройка (один раз, ~10 минут)

### 1. Получить ключ Claude

Открой Терминал на Mac и выполни:

```
$(ls -d ~/.cursor/extensions/anthropic.claude-code-*/ | tail -1)resources/native-binary/claude setup-token
```

(Если Claude Code установлен отдельно, достаточно `claude setup-token`.)

Откроется браузер, нажми «Разрешить». В Терминале появится длинный ключ, начинается на `sk-ant-oat…`.
**Скопируй его**, он понадобится в шаге 4. Никому его не показывай.

### 2. Создать репозиторий

1. Зайди на https://github.com и войди в аккаунт (или зарегистрируйся).
2. Справа вверху **+ → New repository**.
3. Название: `news`. Выбери **Public** (бесплатный сайт бывает только у публичных).
4. Нажми **Create repository**.

### 3. Загрузить файлы

1. На странице нового репозитория нажми ссылку **uploading an existing file**.
2. Открой в Finder папку `News/cloud`.
3. Нажми **Cmd + Shift + .** (точка): появятся скрытые `.github` и `.gitignore`.
4. Выдели всё (**Cmd + A**) и перетащи в окно браузера.
5. Внизу нажми **Commit changes**.

Проверь, что в репозитории появилась папка `.github`. Если её нет:
**Add file → Create new file**, в имени напиши `.github/workflows/news.yml`,
вставь содержимое файла `news.yml` из этой папки и нажми **Commit changes**.

### 4. Вставить ключ Claude

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.

- Name: `CLAUDE_CODE_OAUTH_TOKEN`
- Secret: ключ из шага 1

Нажми **Add secret**.

### 5. Включить сайт

**Settings → Pages → Build and deployment → Source: GitHub Actions**.

### 6. Первый запуск

1. Вкладка **Actions** (если попросит, нажми зелёную кнопку, разрешающую запуск).
2. Слева **Утренняя сводка → Run workflow → Run workflow**.
3. Подожди 2–3 минуты, пока появится зелёная галочка.
4. Сводка откроется по адресу: **`https://<твой-логин>.github.io/news/`**.

## Как читать

- **iPhone / iPad:** открой ссылку в Safari → кнопка «Поделиться» → **«На экран „Домой“»**.
  Появится иконка, открывается в один тап.
- **Windows / Mac:** открой ссылку в браузере и добавь в закладки.

Сводка обновляется каждое утро сама. Если открыл до обновления, потяни страницу вниз, чтобы перезагрузить.

## Как что-то поменять

- **Источники, число новостей, модель:** в репозитории открой `config.json` → значок карандаша →
  правки → **Commit changes**. Применится со следующей сборки.
- **Собрать прямо сейчас:** **Actions → Утренняя сводка → Run workflow**.
- **Время:** в `.github/workflows/news.yml` строка `cron: "30 4 * * *"`.
  Время по Гринвичу: Москва = UTC + 3. Например, `"0 3 * * *"` — это 6:00 по Москве.
- **Остановить:** **Actions → Утренняя сводка → «⋯» → Disable workflow**.

## Если что-то не так

- **Сводки нет / не обновилась:** вкладка **Actions** → последний запуск с красным крестиком →
  открой его и посмотри шаг **«Собрать сводку»**: там написано, что пошло не так.
- **«Claude не ответил» вверху страницы:** скорее всего, истёк ключ (он действует около года).
  Повтори шаг 1 и обнови секрет в шаге 4.
- **Мало российских источников:** серверы GitHub в США, и часть российских сайтов
  (РБК, Коммерсантъ, Лента и др.) их не пускает. Внизу сводки видно, кто не ответил.
- **Страница доступна всем, у кого есть ссылка.** Личных данных там нет, только новости.
  Ключ Claude хранится в секретах GitHub и на страницу не попадает.
